Analyzing Spreadsheet Data with Python

Project Overview

This project focuses on analyzing aviation facility data in Alaska using Python and Pandas. The analysis is performed using an Excel dataset to extract useful information through data manipulation and analysis techniques.

Tools & Technologies

- Python
- Pandas
- Microsoft Excel
- VS Code

Analysis Performed

- Loaded Excel datasets into Pandas DataFrames.
- Identified unique types of aviation facilities.
- Filtered Seaplane Base facilities in Alaska.
- Sorted aviation facilities by elevation.
- Identified the top 5 highest-elevation facilities.
- Calculated average, maximum, and minimum elevation.
- Exported filtered data into a new Excel file.

Python Concepts Used

- Data Loading
- Data Filtering
- Sorting
- Statistical Functions (Mean, Max, Min)
- Excel File Handling

Project Files

- "spreadsheet_analysis.py" – Python analysis code.
- "Airport_Data.xlsx" – Source dataset.
- "README.md" – Project documentation.

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install pandas requests openpyxl"
3. Open the project folder in VS Code.
4. Run "spreadsheet_analysis.py".

Learning Outcome

Gained practical experience in analyzing spreadsheet data using Python and Pandas, filtering records, performing statistical calculations, and exporting analysis results to Excel.
